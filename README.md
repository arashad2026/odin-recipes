# odin-recipes

## Description

Recipe page with list of recipes where each link goes to the recipe page. Each page contains:

- Link to homepage
- Heading with recipe name
- Image of the recipe
- Description of the recipe
- Image of the recipe
- unordered list of ingredients
- ordered list of steps

## Lessons learned
- Create html pages
- link pages with hyperlinks
- Headings for hierarchy
- embedding images
- Paragraphs for text
- unordered list
- ordered list
